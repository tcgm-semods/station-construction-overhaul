# Station Construction Overhaul

A Star Empire mod that rebuilds the **Construction** tab of a player station.

![Construction tab: live progress, ETA, one-click BUILD and a requirements tooltip](docs/construction-tab.png)

See [`source/README.md`](source/README.md) for details.

## Install

Grab the latest `.semod` from [Releases](../../releases/latest) and drop
it into the Star Empire Mod Manager.
